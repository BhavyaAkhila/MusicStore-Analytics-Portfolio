# MusicStore-Analytics-Portfolio
## 📖 Project Overview

This project analyzes a Music Store database using **PostgreSQL** to solve real-world business problems through SQL. The analysis focuses on customer behavior, sales performance, artist popularity, and revenue trends to generate meaningful business insights.

This project demonstrates SQL skills commonly required for **Data Analyst**, **Business Analyst**, and **SQL Developer** roles.

---

## 🛠️ Tech Stack

- PostgreSQL
- pgAdmin 4
- SQL
- Git
- GitHub
## 🎯 Project Objectives

- Analyze customer purchasing behavior.
- Identify the highest spending customers.
- Determine countries and cities generating maximum revenue.
- Analyze music genres and artist performance.
- Generate actionable business insights using SQL.

## 📊 Business Questions Solved

### Basic Analysis

- Find the senior-most employee.
- Identify countries with the highest number of invoices.
- Find the top invoice values.
- Determine the city with the highest revenue.
- Identify the best customer.

### Customer Analysis

- Find Rock music listeners.
- Calculate customer spending on artists.
- Identify the highest spending customer in each country.

### Sales Analysis

- Find the top Rock artists.
- Identify tracks longer than the average song length.
- Determine the most popular music genre by country.

## ▶️ How to Run

1. Clone this repository.

```bash
git clone https://github.com/BhavyaAkhila/MusicStore-Analytics-Portfolio.git
```

2. Open PostgreSQL or pgAdmin.

3. Create a new database.

4. Execute:

```
database/Music_Store_Schema.sql
```

5. Execute:

```
database/Music_Store_Data.sql
```

6. Run the SQL queries inside the **queries** folder.
